# Аналитика и бюджеты

Раздел «Аналитика» показывает подтверждённые доходы и расходы по категориям за выбранный месяц. Внутренние переводы исключаются; отдельно учтённая комиссия остаётся расходом. Предварительные уведомления Android пока не входят в расчёт: для безопасного автоматического учёта сначала необходимо сопоставление с выписками и защита от двойного счёта.

Бюджет задаётся для категории расходов, действует с выбранного месяца и повторяется в последующих месяцах. Изменение или отключение начинает действовать с выбранного месяца и не переписывает более ранние лимиты. Для категории без операций можно задать лимит кнопкой «Установить бюджет». Общая сумма лимитов и расходов по ним относится только к категориям с заданными лимитами; общий расход включает все категории. Превышение показывается в интерфейсе; фоновые push-уведомления о превышении не настроены.

Основную валюту можно выбрать в аналитике или в настройках. Лимит сохраняется в указанной при создании валюте, поэтому смена основной валюты не меняет исходное число лимита. Для расхода при совпадении основной валюты с валютой операции используется сумма операции, а при совпадении с валютой счёта — фактически списанная сумма по счёту. В остальных случаях приложение переводит сумму по актуальному безналичному курсу покупки ACBA со страницы Rate.am через AMD. По тому же курсу пересчитываются лимиты, заданные в другой валюте. Округление выполняется до двух знаков при переводе каждой группы операций за день в валюте и на счёте. Курсы покупки используются как ориентир для отображения, а не как утверждение о фактическом курсе покупки/продажи конкретной операции.

Публичная страница Rate.am даёт текущие котировки, проверенный общедоступный архив безналичных курсов ACBA на даты прошлых операций не найден. Поэтому пересчёт старых месяцев по этому источнику приблизителен и может меняться; дата котировки показывается на экране. Интеграция зависит от структуры публичной страницы и при её изменении может перестать работать. Если курс необходим, но недоступен, аналитика сообщает об ошибке вместо выдуманной суммы. В Rate.am отправляется только запрос страницы курсов без пользовательских данных и операций.

Для локальной проверки запустите Edge Functions в существующей локальной сети:

```bash
npx --yes supabase@3 functions serve exchange-rates --network-id cash-radar-loopback
```

Далее запустите Flutter Web с `app/config/local-supabase.json`. Production-функция разворачивается вместе с остальными Supabase-функциями после слияния в `main` и успешных проверок.

## Подробная аналитика за период

Ниже помесячной диаграммы можно выбрать произвольный включительный диапазон дат. Отчёт показывает доходы, расходы, расходы по категориям и изменение относительно непосредственно предшествующего периода такой же длины в календарных днях. Динамика показывает шесть полных календарных месяцев, заканчивая месяцем окончания выбранного периода; поэтому при выборе неполного месяца график может включать операции за пределами выбранных дат.

Общий баланс — сумма текущих остатков только активных счетов, пересчитанных в основную валюту. Отрицательные остатки учитываются со знаком. Архивные счета не входят в баланс, но их операции включены в обороты выбранного периода и отражаются в разбивке по счетам. Разбивка по валютам показывает оригинальные суммы операций без смешивания валют. Все разделы исключают подтверждённые внутренние переводы и включают отдельно учтённую комиссию. На текущий баланс не влияют предварительные уведомления.

Пересчёт расходов группируется по дате, счёту, категории, типу и исходной валюте до округления. Для соседних разделов текущая котировка кешируется на пять минут; исторические периоды по-прежнему используют текущий курс, если фактическая сумма в выбранной валюте недоступна. Общий баланс отражает текущие остатки, а не срез на конец выбранного периода.

Проверка сквозного расчёта на локальном Supabase (создаёт и удаляет временного тестового пользователя):

```bash
cd app
TZ=Asia/Yerevan flutter test --no-pub --dart-define-from-file=config/local-supabase.json \
  --dart-define=RUN_LOCAL_PERIOD_REPORT_TESTS=true test/local_period_report_integration_test.dart
```

Перед проверкой должна быть запущена локальная Edge Function курсов. Тест обращается к Rate.am за текущими публичными котировками и не использует финансовые операции пользователя.
