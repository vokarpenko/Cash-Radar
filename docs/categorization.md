# Категоризация без AI

В «Настройки → Правила категорий» можно добавить правило по части названия, точному названию или четырёхзначному MCC. Правило задаёт тип операции, категорию и приоритет от 0 до 10000; более высокий приоритет проверяется раньше. При одинаковом приоритете выигрывает более конкретное название, затем более раннее правило. Правило можно отключить или удалить. Явно заданные пользователем правила имеют приоритет перед остальными способами.

Алиас связывает исходное название с общим; для него можно сразу выбрать категорию или оставить её пустой и использовать правило для общего названия. Затем проверяется правило MCC и, если ничего не подошло, запомненное исправление. Если соответствия нет, используется категория по умолчанию. Никаких предустановленных предположений о торговых точках нет; категории и правила владелец выбирает сам.

При изменении категории существующей операции запоминается нормализованное название этой операции и новый выбор. Такие соответствия видны в настройках и могут быть удалены. Приоритет пользовательских правил выше запомненных исправлений. Для ACBA берётся отдельное поле места операции, для Ameria — исходное описание, так как надёжно выделить из него merchant пока нельзя. Исходные данные не изменяются. MCC применяется только при наличии корректного кода в данных парсера; имеющиеся проверенные выписки не дают подтверждённого поля MCC, разбор Альфа-Банка отложен.

Правила применяются к новым строкам банковских выписок до предпросмотра. В уже подготовленной банковской выписке их можно применить повторно кнопкой «Применить правила категорий». Явные категории CashRadar CSV и ручной ввод сохраняются без автоматической замены. Изменение правил не переписывает прошлые операции. В предпросмотре виден источник категории; комиссия остаётся отдельным расходом. Названия и правила доступны только владельцу через политики RLS. AI и внешние сервисы не используются.
